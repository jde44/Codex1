# Web Prototypes

Three static UX/UI prototypes for enabling the `targeted-job-application-resume` skill.

## Prototype 1: Pipeline Command Center

File: `prototype-1-command-center/index.html`

Focuses on job search monitoring, fit scoring, source performance, approval queues, and application pipeline KPIs.

## Prototype 2: Application Deal Desk

File: `prototype-2-application-deal-desk/index.html`

Focuses on evaluating one role at a time, with scorecards, evidence mapping, conflict checks, and application package readiness.

## Prototype 3: Daily Report Board

File: `prototype-3-daily-report/index.html`

Focuses on daily reporting, trend metrics, applied/prepared/skipped roles, blockers, and follow-up actions.

## How To Open

Open any `index.html` file in a browser. No build step or server is required.
