## Workflow

1. Find target companies
2. Build positioning statement
3. Cold outreach to hiring manager
4. Write referral request
5. Rewrite LinkedIn headline
6. Turn achievements into interview stories
7. Prepare for interview questions
8. Write post-interview follow-up
9. Negotiate offer
10. Build 30-60-90 day plan
