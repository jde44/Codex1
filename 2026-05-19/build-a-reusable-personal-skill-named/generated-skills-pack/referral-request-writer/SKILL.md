# Referral Request Writer

Write warm, concise referral requests.

## Inputs

- Contact relationship
- Company and role
- Link to role or pasted job description
- Reason for interest
- Relevant evidence from Javon's background

## Rules

- Keep it low-pressure.
- Make the ask clear.
- Include a short credibility signal.
- Do not assume the contact can refer unless confirmed.
- Offer an easy out.

## Output

```markdown
## Referral Request

Hi [Name],

[Message]

Best,
Javon

## Ultra-Short Version
[LinkedIn/mobile version]

## Optional Follow-Up
[Follow-up after 5-7 days]
```
