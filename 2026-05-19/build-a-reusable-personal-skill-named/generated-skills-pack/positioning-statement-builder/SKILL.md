# Positioning Statement Builder

Build clear, evidence-grounded positioning statements.

## Inputs

- Target role or company
- Desired emphasis
- Known evidence from JobPilot profile, resume, LinkedIn, or user-provided facts
- Audience: recruiter, hiring manager, executive, referral, LinkedIn, interview

## Rules

- Keep language plain, direct, and senior.
- Avoid buzzwords.
- Do not invent metrics or achievements.
- Frame AI training as professional development unless certification is verified.
- Use client-anonymized language by default.

## Output Options

```markdown
## Positioning Statement

### 15-Second Version
[1-2 sentences]

### 30-Second Version
[3-4 sentences]

### LinkedIn / About Version
[Short paragraph]

### Recruiter Version
[Direct recruiter-facing version]

## Evidence Notes
- Supported by:
- Needs confirmation:
```
