# Staging App

This is the finalized staging prototype for approval before production.

It consolidates the three earlier prototype directions into one single-page web app:

- `Pipeline Command Center`
- `Application Deal Desk`
- `Daily Report Board`

The command-center sidebar controls all three views. The app is static HTML/CSS/JavaScript and can be opened directly in a browser.

## Open

`web-prototypes/staging-app/index.html`

## Test

```bash
node web-prototypes/tests/staging-app-smoke.mjs
```
