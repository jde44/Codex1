# ATS Quality Check

Run before finalizing the targeted resume.

## ATS Keyword Alignment

- Role title or close variant appears in headline or summary.
- Company/job keywords are represented naturally, not stuffed.
- Required regulations, frameworks, domains, and tools are included only when supported.
- Seniority words match the posting: manager, senior manager, director, lead, advisory, governance, remediation, transformation.
- Core job themes are visible in summary, skills, and experience bullets.

## Formatting Check

- No tables, columns, text boxes, icons, graphics, or images.
- Standard section headings are used.
- Bullets are concise and readable.
- Dates, titles, company names, and locations use a consistent structure.
- Contact details are plain text.
- Acronyms are used with enough context when helpful.

## Seniority Alignment

- Resume shows appropriate leadership scope without overstating authority.
- Stakeholder level aligns to the job, such as executive, CISO, CRO, compliance, audit, legal, operations, or technology.
- Bullets show ownership, advisory, coordination, and delivery at the correct level.
- Tactical work is included only when it supports the target role.

## Tone Check

- Sounds like Javon: professional, direct, clear, warm.
- Avoids buzzword-heavy phrasing.
- Avoids exaggerated claims.
- Avoids generic phrases such as "dynamic leader" or "proven track record."
- Reads like a credible human resume, not a generated marketing document.

## Final ATS Result Format

```markdown
ATS Quality Gate:
- Keyword alignment: Pass / Needs revision - [reason]
- Formatting: Pass / Needs revision - [reason]
- Seniority alignment: Pass / Needs revision - [reason]
- Tone: Pass / Needs revision - [reason]
```
