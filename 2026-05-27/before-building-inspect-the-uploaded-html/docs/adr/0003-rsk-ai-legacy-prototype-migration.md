# ADR 0003: RSK AI Legacy Prototype Migration

## Status

Accepted

## Context

The product lineage includes a prior Claude-generated prototype named Zess AI and a broader Next.js app that used the Zess AI brand and Ready / Set / Grow architecture.

## Decision

Preserve Zess AI as historical lineage only.

Use active RSK AI naming for the current app, docs, deployment files, and future branch work:

- RSK AI as the app/platform name
- Ready Set Know as the website architecture
- Ready / Set / Know as the maturity model
- PARCM as the core operating method

## Consequences

The legacy prototype remains available for product-memory reference through git history and migration notes, but future work should target RSK AI naming and Ready Set Know architecture.
