# ADR 0002: RSK AI MVP Scope

## Status

Accepted

## Context

The prototype included a broad AI governance command center with use case intake, risk scoring, PARCM mapping, evidence vault, decision log, issue tracker, report builder, prompt firewall, shadow AI detection, model mix governance, board KPIs, and early warnings.

This is too broad for a first product release.

## Decision

The MVP will focus on three use cases:

1. AI Use Case Governance
2. Regulated Workflow Control Mapping
3. Evidence & Governance Memo Generation

The first product module is AI Use Case Governance.

The core user journey is:

Submit AI use case -> classify risk -> map PARCM controls -> generate governance memo.

## Consequences

Broad GRC features remain parked until the first workflow is clear, demoable, and credible.
