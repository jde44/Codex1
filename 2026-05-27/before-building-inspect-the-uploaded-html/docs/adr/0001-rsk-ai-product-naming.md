# ADR 0001: RSK AI Product Naming

## Status

Accepted

## Context

The AI governance app has used several working names, including Zess AI, Veris, BridgeLayer, Ready Set Grow, and Ready Set Know. The names created product drift and made it unclear which brand should be used for the website, platform, and methodology.

## Decision

Use the following hierarchy:

- Public site / brand architecture: Ready Set Know
- App / platform: RSK AI
- Legacy prototype: Zess AI
- Methodology: PARCM
- First module: AI Use Case Governance

Zess AI is preserved as a legacy prototype name but is not the final public product name.

## Consequences

The codebase may preserve the original Zess lineage as a legacy artifact, but all active product screens, filenames, deployment assets, and source-of-truth docs should use RSK AI and Ready Set Know.
